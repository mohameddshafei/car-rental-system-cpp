# Car Rental System in C++

## Overview
This is a C++ object-oriented programming project that simulates a basic car rental system. The program allows users to add vehicles, update vehicle details, search for vehicles, book available vehicles, create customer accounts, check availability, and generate rental invoices.

The project demonstrates core OOP concepts such as classes, objects, constructors, destructors, encapsulation, dynamic arrays, and menu-driven programming.

## Features
- Add new vehicles
- Update vehicle details
- Search vehicles by model
- Book available vehicles
- Check vehicle availability
- Create customer accounts
- Generate rental invoices
- Menu-driven console interface

## Classes Used

### Vehicle
Stores vehicle information such as:
- Vehicle ID
- Brand
- Model
- Daily rental price
- Availability status

### Customer
Stores customer information such as:
- Customer ID
- Name
- Phone number

### RentalSystem
Manages the full rental system, including:
- Vehicle records
- Customer records
- Vehicle booking
- Availability checking
- Invoice generation

## Concepts Practiced

- Classes and objects
